# AI 官方来源与模型版图取证

先固定问题中的产品/模型变体、版本、日期、地区与消费端/API/开源权重渠道。保留用户指定来源与比较对象，恢复已有证据后补最有区分力的缺口。

## 来源与存在性

- 从厂商官方主页、明确关联的文档/模型卡/代码组织建立来源链。robots/sitemap 是页面发现线索，不能自行证明域名官方性或完整覆盖。
- 记录最终 URL、获取时间、HTTP 状态与实际正文。200 可能是登录、WAF、软404或通用 JS shell；比较标题、正文语义与同路由不存在页面，必要时用浏览器读取。字节长度仅作异常线索，不设10KB门槛。
- 401/403/404、网络失败、空搜索分别记录。未授权私有/gated 仓可能隐藏存在性；只写“在本次权限与检索范围未确认”，不能以三源全阴证明全球不存在。
- 官方发布、文档可见、API可调用、权重可下载、代码可运行分别核查。产品名不等于API model id；原始ID来自当前官方模型/定价清单，文本出现次数不等于服务可用。
- 论文的官方性结合官网链接、作者/机构、模型卡及仓库关联确认，不能只看第一作者字符串。官方维护的 fork 也可能是有效实现，标明 upstream/fork 和实际改动。

## 数字与比较

规格和价格绑定精确 model id、snapshot/alias 语义、上下文档位、effort、输入/输出/缓存/批处理计费单位、地区和生效日期；促销与常规价分列。能力自报与第三方评测分开，保留 benchmark/harness版本、样本、预算、工具、硬件和评测日期。两处数字接近不能证明其他指标可靠。

比较使用情境与约束相同的候选；不同effort名称不保证等计算预算，提供默认档/相近成本/最高质量等有意义切面。rank必须带候选集合、过滤条件与分母，不跨族直接比较名次。任务成本与延迟应考虑输出和推理token，不能只按每百万token单价排序。

HF 参数元数据、config声明dtype、文件体积和模型卡分别保留口径；量化/打包权重不可直接从 safetensors.total 推逻辑总参数。权重完整性与真实dtype可用已安装 `ascend-server-layout` 的只读检查器。二进制下载用当前平台的真实文件解析地址，检查magic/内容与校验和，识别LFS指针；不把 `/raw/` 永久当可用或不可用。

详细检索与动态页面边界见 [references/source-checks.md](references/source-checks.md)。交付引用靠近结论，标注未取到的证据与矛盾口径；研究报告不冒充代码/基准复现。

## 版本号与 GA/preview：分数不可并排的四种情况

触发信号：引用任何榜单分数、或比对「官方说多少分」与「榜上多少分」之前。**版本号不是元数据，是分数的一部分。**

下面几个分数只是示例（2026-11 快照，本轮未复验），用来说明「同一模型换版本就差十几分」的量级与方向，引用前必须以现场榜单页的当前版本号与分为准。

- **大版本跳变严禁并排**：同一模型、同一组合，跨榜单大版本可以掉十几分——AA Coding Agent Index 从 v2.0 到 v2.1，同模型同 CLI 由 48.9 变 40.1；Intelligence Index 由 v4 到 v5.0.1，同模型由 55 变 46。只写「某模型 X 分」而不写版本，等于没写。
- **厂商自报分要追问它当年对应哪个版本**：官方口径常是发布当时的旧版本，隔几个月被当现行分数引用（官方宣称 60 分、第三方记录 v4.3 为 45、现行 v5.0.1 为 32，三值并存）。同一模型出现三个数时，先按版本归档，再取最新一版，其余标「旧版本」。
- **GA 与 preview 是两个 model id，不是同一模型的阶段**：榜单条目常只覆盖 preview，GA 上线后榜方未重测。引用前确认 id 后缀、发布日期与 preview 退役日；拿 preview 分点评 GA 是最常见的错配。
- **名次比百分数更不可靠**：累计榜会随新模型入场重排，同一模型在不同快照里能落到相隔数位的名次。引用个人榜只引「日期 + 百分数 + 题量」，不引名次。
- **窗口早于发布 = 覆盖空白**：滚动窗口类榜（如 SWE-rebench）的时间窗若早于模型发布日，整列为空属于「未覆盖」，不是「跑输」。

拿不准的写法：`未验证：<数值>（来源层级 / 版本 / 抓取日）`。
