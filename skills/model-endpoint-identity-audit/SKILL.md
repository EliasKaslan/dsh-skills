# 模型端点行为与身份核查

先恢复端点、model id、供应商声明、允许测试的预算/并发/数据范围。只在用户授权的账号与额度内调用，不把大上下文压力测试当无成本只读检查。用最小合成输入，避免跨供应商传播私人或工作材料。

控制实际发送的messages、系统/developer角色、模板、工具、图像编码、采样参数、reasoning、缓存和路由；直连与agent框架两条路径分开。错误角色白名单先查客户端序列化和网关兼容，不直接归因模型权重，DSH compat字段按当前DSH版本的schema核查，不当成模型API通用字段。

## 身份证据的上限

- model回显、模型自述和目录名是供应商/接入层声明。
- prompt_tokens相同、图像token相同和短输出相同可支持行为兼容，不能证明相同tokenizer、视觉前端或权重；隐藏模板、记账与常见答案会制造一致。
- 缓存互通只支持“可观察的共享缓存/路由或记账行为”。相同权重可在不同部署隔离缓存，不同权重也可共享网关缓存/响应。既不能把互通称同权重决定性证据，也不能从不互通判不同模型。
- 更强身份依据是可核验的模型版本/digest、部署配置与供应商证明，仍注明是否能独立验证。无法取得时保留未知。

## 有界实验

先测同端点重复性，再做随机化顺序和多轮对照；文本/图像token统计、缓存命中、短任务与实际用户任务分开。temperature=0通常仍是贪心选择，但并行/路由/浮点及后处理可导致非逐位复现；输出不同不能独自证明权重不同。

缓存实验用唯一合成前缀、同ID二次阳性对照、跨ID双向对照与实际cached_tokens。随机nonce可降低精确前缀复用，不能保证网关一定冷缓存。冷预填充、TTFT、首个答案、生成吞吐和总时延分别计，读取真实usage/缓存策略并记录缺字段。

能力矩阵按实际需要逐项测试schema约束、logprobs、工具回路、视觉、上下文和reasoning参数。HTTP200不等于schema被执行、n条输出齐全或logprobs有效；错误原文、null、NaN/Inf与异常哨兵需保留。工具返回必须对应真实call ID/名称和参数，不能用错装置制造模型失败。

上下文上限通过文档+有预算的边界测试验证，错误中一个数字可能是网关限制。输出截断检查finish_reason/reasoning tokens，不规定8192等通用最低预算。价格单位从官方价目/账单核实，不能由credit数值看起来合理就推美元/百万token。

交付身份声明、观测事实、可支持推断与未能证明部分，再按任务给能力/延迟/成本比较。来源：旧同名DSH skill，2026-11-16重写，未实际调用付费模型端点。
