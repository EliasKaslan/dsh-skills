# 判境外 AI 服务在中国大陆的可用性

## 何时调用

- 用户问「X 能在中国大陆用吗 / 我想拿它当生产力工具」：ChatGPT、Claude、Gemini、Cursor、Notion AI、Copilot 之类。
- 同族问题：「国内云能不能调到这个模型」「这笔订阅能不能开发票走对公」「文档喂进去算不算数据出境」。
- 不适用：纯模型能力选型（那是另一类调研）；也不提供任何规避手段、工具名、配置步骤或中转商推荐——只陈述事实与风险。

## 第一步：拆成四道门，不要笼统答「能 / 不能」

1. **网络可达**：消费级域名（网页版/App）与 API 端点要分别核，两者经常不一致。港澳台口径单独看，别和大陆混为一谈。
2. **账号地区**：查官方支持地区页 + 资格判定规则（常见是「注册时所在地 + 过去一年主要所在地」）。「仅 Workspace / 仅企业」是被标为不支持地区的常见折中口径。
3. **付费与开票**：多数要求「国家 + 付款方式 + 币种」三者一致，改国家有冷却期（见过 12 个月）；跨境个人订阅通常开不了国内发票。
4. **API 多一层**：即便网络可达，region 白名单不含大陆时返回 `400 ... User location is not supported for the API use`。企业通道（云厂商区域端点）与消费级订阅是两条不同的路，要分开答。

## 第二步：把「生产力工具」的隐性成本说清

用户问的是工具，实际要的是「每天能用、断了有备胎、花的钱能入账、资料能合规出境」。四条：

- 断供风险：风控判的是「IP / 地区 / 语言与账号不一致」，不会提前告警，只在关键时刻断。个人无申诉通道。
- 无法报销：个人跨境订阅开不了国内发票。
- 数据出境：工作文档涉及个人信息 / 重要数据出境须先过评估。
- 个人用第三国账号属条款风险，别把「能跑」当「能长期用」。

结论句式建议：别回答「能不能连上」，回答「断了有没有备胎、钱能不能入账、资料能不能出境」。

## 合规条款（已逐字核对原文）

《计算机信息网络国际联网管理暂行规定》（2024-03-10 第二次修订，国务院令第 777 号，2024-05-01 施行）

- 第六条：计算机信息网络直接进行国际联网，必须使用国家公用电信网提供的国际出入口信道。任何单位和个人不得自行建立或者使用其他信道进行国际联网。
- 第十四条：违反第六条、第八条、第十条的，由公安机关责令停止联网，给予警告，可以并处 15000 元以下的罚款；有违法所得的，没收违法所得。

条文原文（司法部国家行政法规库）：https://xzfg.moj.gov.cn/front/law/detail?LawID=1713

## 第三步：给三条「正道」，按代价从低到高排

1. 境外主体 + 云厂商区域端点：合规、可审计、有账单，但属企业采购，不是个人工具。
2. 偶发硬需求（超长文 / 原生多模态）按次买，**不进关键路径**。
3. 个人第三国账号：能跑，代价是上面四条，定位为备胎。

## 常见误区（先查再断言）

- 「国内云厂商的模型市场会合法代理境外模型」：主流国内云通常不官方上架境外厂商模型，别预设存在。
- 「标称上下文 = 有效上下文」：中文长文有效深度常远低于标称，重要文档仍要分段。

## 调研落实方式（真跑通过）

两条并行子代理：①事实链（网络 / 账号地区 / 付费 / API / 区域端点 / 风控）；②替代方案与价格矩阵。主 agent 只做两件事：抽查官方页是否真取到原文、把最吃重的法条逐字核对。

坑：官方「支持地区」页经常被截断或 302 跳到登录页，取不到正文时**必须标明「依据多家独立来源对同一页面的复述」**，不能假装读到原文。

## 未验证：/ 每轮必重查

- 各家地区名单、免费额度、定价变动极快：本 skill 不存任何「某服务当前支持/不支持」的结论，当轮重新检索。
- 香港/澳门是否已开放、是否仅 Web 版，历史来源互相矛盾，未验证。
- 「必须非 +86 手机号」属社区说法，未见官方口径，未验证。

## ## 境外手机号：能持有、能收码，但只解决四分之一

## 何时调用（补充）

用户接着问「怎么搞一张海外手机号 / 能不能正常收短信」时进来——这是「境外服务在大陆可用性」的下游问题，别当独立话题重开调研。

## 五条路的真实排序（别让用户以为都能走）

| 路径 | 能否稳定收码 | 门槛 | 判断 |
|---|---|---|---|
| 实体境外 SIM + 国际漫游 | 能，漫游时**接收短信普遍免费** | 双卡机空一槽；需定期产生消费保号 | 唯一推荐 |
| 境外 eSIM | 国行机基本不行 | 国行 iPhone 仅少数机型有 eSIM，且**境内装不了境外 eSIM**（位置/电子围栏）；国内运营商 eSIM 须线下核验身份证 | 走不通 |
| eSIM 转实体卡适配器 | 不稳 | 出现过连网后被网络拒绝并烧卡、白卡 EID 被拉黑、卖家跑路 | 别承载主号/银行验证码 |
| 虚拟号 / OTT（GV、TextNow） | 收得到一部分 | 平台按号码类型判定直接拒收 | 不算「正常短信」 |
| 买「已实名卡 / 黑卡」 | 能 | 违法 | 红线，不讨论 |

## 虚拟号为什么不算「正常短信」

平台是**按号码类型筛选**的，不是按能不能收码。可核实证据：

- Microsoft 官方：「VOIP numbers can't be used for sign-in or verification codes; a mobile number is required」
- WhatsApp FAQ 把 VoIP、Landline 列为 unsupported numbers
- Twilio Lookup「Line Type Intelligence」对外返回 mobile / landline / fixedVoip / nonFixedVoip —— 说明平台侧确实有判定能力
- 典型失败：提交即提示不能用于验证 / 重复索码收不到 / 注册后 1–3 天封号

Google Voice 本身是 VoIP，且开通需先用一个美国**非 VoIP** 实卡号做一次性验证；TextNow 之类免费号段已被 Google 识别拒发。

## 唯一推荐路径的实操要点

- 漫游**只收不发**：花钱的只有发短信、接电话、上网；开通国际漫游本身通常免费。
- **必须关掉该卡的数据漫游**——否则后台流量按 MB 计费，是这类方案最常见的意外支出。
- **保号的关键是「定期产生消费」，不是「账户有余额」**：多数预付卡要求在保号周期内有一笔充值或一次使用，否则号码回收。各运营商周期不同，下单前按官网核。
- **二手号风险**：储值卡号码大量是回收再编配的（常见口径为超两年无人使用即重新分配）。买到的可能是别人注册过 Google / Telegram 的旧号——验证码发到陌生人那里，或平台判定号段异常。要认全新号段，拿到后立刻自己接管绑定。
- **号段限制**：部分地区新增号段（如香港 4/7/8 字头）部分 App 不支援，买前看号段。
- **别用预付卡给银行/主账号做二次验证**：忘了充值就失效，届时解锁账户很麻烦。

## 实名办理的口径差异（决定能不能远程办）

- **香港**：实名可在**线上远程完成**（法规未要求亲身在港），无 HKID 者用有效旅行证件；个人在每家运营商有登记张数上限。注意有产品线停过又恢复，在售状态必须现查。
- **澳门**：购卡**必须本人到场**出示证件正本，无法远程。
- 日本：签约时「本人确认」为法定义务，且未经运营商同意转让他人使用构成违法。
- 美国：无联邦级 SIM 实名法，预付卡可无 SSN 购买；英国：购卡无需实名。

## 法律红线（条文已核，写死）

**能做**：以本人真实身份、本人证件在境外运营商实名购卡，在大陆漫游收码通话，属正常电信服务合同，无明文禁止。

**绝对不能做**：

1. 买卖 / 出租 / 出借电话卡 → 《反电信网络诈骗法》第 31 条第 1 款；第 44 条：没收违法所得，处违法所得 1–10 倍罚款，无违法所得或不足二万元的处二十万元以下罚款，情节严重并处十五日以下拘留。
2. **「20 张」线已很低**：两高一部 2025-07-28《意见》——收购/出售/出租电话卡 20 张以上即「情节严重」，**不再区分他人卡还是本人卡**；帮信罪（刑法第 287 条之二）三年以下有期徒刑或拘役。
3. 买「他人已实名」的卡：买方同样落入第 31 条「非法买卖电话卡」；明知用于犯罪则帮信罪；卡上带他人身份信息还可能叠加侵犯公民个人信息罪。香港侧：买卖已登记卡可触《盗窃罪条例》第 18A 条、《刑事罪行条例》第 73 条，刑期远重于内地。
4. 代人实名、代人收码转码：这是从行政罚跳到刑事罚的那一步。

**「持号」与「用该号访问被阻断服务」要分开说**：后者落入《计算机信息网络国际联网管理暂行规定》第六条（必须使用国家公用电信网提供的国际出入口信道，不得自行建立或使用其他信道）。**境外卡漫游是否属于「其他信道」目前无权威解释、无公开处罚案例**（公开案例均针对 VPN）——这是解释空白，不是「合法确认」，按「风险未知」表述，不要说成没事。

## 必须纠正的用户预期（最容易省下冤枉钱的一条）

号码只是**四道门里的第一道**。要「正常使用」需**号码 + 账号地区 + 支付方式 + 稳定可达网络**四项同时成立：

- Google：账号国家/地区按**创建时所在地** + 过去一年最常停留地判定，改区约需一年
- OpenAI：支持地区按**访问所在地**判定
- Apple：改 App Store 地区须先提供该国付款方式与账单地址

所以先问用户「其余三项你能凑齐几项」。只缺收码才买卡；其余都缺，买卡是白花钱。

## 未验证：

- 港澳实名与产品政策 2026 年内有反复（有产品暂停后恢复、不同来源对「内地身份证是否受理」说法矛盾），必须现查。
- 各国预付卡保号周期、漫游资费差异大且常调，本 skill 不存具体金额，按官网核。
- 内地对「境外号漫游收短信」是否有新增限制，未检索到明确口径。
