# 判境外 AI 服务在中国大陆的可用性

## 何时调用

- 用户问「X 能在中国大陆用吗 / 我想拿它当生产力工具」：ChatGPT、Claude、Gemini、Cursor、Notion AI、Copilot 之类。
- 同族问题：「国内云能不能调到这个模型」「这笔订阅能不能开发票走对公」「文档喂进去算不算数据出境」。
- 不适用：纯模型能力选型（那是另一类调研）；也不提供任何规避手段、工具名、配置步骤或中转商推荐——只陈述事实与风险。

## 第一步：拆成四道门，不要笼统答「能 / 不能」

1. **网络可达**：消费级域名（网页版/App）与 API 端点要分别核，两者经常不一致。港澳台口径单独看，别和大陆混为一谈。
2. **账号地区**：查官方支持地区页 + 资格判定规则（常见是「注册时所在地 + 过去一年主要所在地」）。「仅 Workspace / 仅企业」是被标为不支持地区的常见折中口径。
3. **付费与开票**：多数要求「国家 + 付款方式 + 币种」三者一致，改国家有冷却期（见过 12 个月）；跨境个人订阅通常开不了国内发票。
4. **API 多一层**：即便网络可达，region 白名单不含大陆时返回 `400 ... User location is not supported for the API use`。企业通道（云厂商区域端点）与消费级订阅是两条不同的路，要分开答。

## 第二步：把「生产力工具」的隐性成本说清

用户问的是工具，实际要的是「每天能用、断了有备胎、花的钱能入账、资料能合规出境」。四条：

- 断供风险：风控判的是「IP / 地区 / 语言与账号不一致」，不会提前告警，只在关键时刻断。个人无申诉通道。
- 无法报销：个人跨境订阅开不了国内发票。
- 数据出境：工作文档涉及个人信息 / 重要数据出境须先过评估。
- 个人用第三国账号属条款风险，别把「能跑」当「能长期用」。

结论句式建议：别回答「能不能连上」，回答「断了有没有备胎、钱能不能入账、资料能不能出境」。

## 合规条款（已逐字核对原文）

《计算机信息网络国际联网管理暂行规定》（2024-03-10 第二次修订，国务院令第 777 号，2024-05-01 施行）

- 第六条：计算机信息网络直接进行国际联网，必须使用国家公用电信网提供的国际出入口信道。任何单位和个人不得自行建立或者使用其他信道进行国际联网。
- 第十四条：违反第六条、第八条、第十条的，由公安机关责令停止联网，给予警告，可以并处 15000 元以下的罚款；有违法所得的，没收违法所得。

条文原文（司法部国家行政法规库）：https://xzfg.moj.gov.cn/front/law/detail?LawID=1713

## 第三步：给三条「正道」，按代价从低到高排

1. 境外主体 + 云厂商区域端点：合规、可审计、有账单，但属企业采购，不是个人工具。
2. 偶发硬需求（超长文 / 原生多模态）按次买，**不进关键路径**。
3. 个人第三国账号：能跑，代价是上面四条，定位为备胎。

## 常见误区（先查再断言）

- 「国内云厂商的模型市场会合法代理境外模型」：主流国内云通常不官方上架境外厂商模型，别预设存在。
- 「标称上下文 = 有效上下文」：中文长文有效深度常远低于标称，重要文档仍要分段。

## 调研落实方式（真跑通过）

两条并行子代理：①事实链（网络 / 账号地区 / 付费 / API / 区域端点 / 风控）；②替代方案与价格矩阵。主 agent 只做两件事：抽查官方页是否真取到原文、把最吃重的法条逐字核对。

坑：官方「支持地区」页经常被截断或 302 跳到登录页，取不到正文时**必须标明「依据多家独立来源对同一页面的复述」**，不能假装读到原文。

## 未验证：/ 每轮必重查

- 各家地区名单、免费额度、定价变动极快：本 skill 不存任何「某服务当前支持/不支持」的结论，当轮重新检索。
- 香港/澳门是否已开放、是否仅 Web 版，历史来源互相矛盾，未验证。
- 「必须非 +86 手机号」属社区说法，未见官方口径，未验证。
