# LoRA 周报主题配方

历史仓库顺序：vllm-project/vllm、vllm-project/vllm-ascend、sgl-project/sglang；本轮按用户范围增减。关键词LoRA大小写不敏感，标题精确召回可补正文、目录和标签，记录噪声与漏召回边界。CI、测试、bugfix、perf与模型改动都可相关，不只收feature。

既有简报格式可用“概览 + 三仓”四节，每仓表列PR链接、北京时间、合入背景、改了什么、影响；按合入时间正序便于看演进。用户要求详细版时扩展具体机制，不预设必须询问才能继续。表格中的pipe/换行需转义或改写，确保链接保留。

概览合入总数只等于merged行数；0合入可以明确写0并在独立在途区域列候选。不能把“未合入（在途）”填进表后也计作merged。既有“每格40~80字、至少5处加粗”是写作样例，不是数据正确性门禁。

每条PR解释前读实际diff/正文和测试证据；标题相似不等于两框架已经具备相同能力。周报只报告该时间窗，不用预期条数凑数，不因0条推断无相关工作。
