# 案例模板

复制到同目录的 `cases/`，替换说明性字段。仅填写本轮确有证据的范围；可删除不适用段落，不将未执行项目写成 PASS。

## 身份与结论

- 案例 ID、日期、状态：VERIFIED_SCOPED / PARTIAL / FAILED / HYPOTHESIS。
- 模型结构与关键几何、文本/多模态等输入范围。
- 训练/推理框架及实际源码/产物指纹、芯片和运行环境。
- 目标：原始位一致或预先约定误差预算；评分语义、dtype、有效范围。
- 一句话结果及未覆盖边界。

## 环境和任务契约

记录实际版本、关键精度/量化链、并行拓扑、cache/Graph/recompute、确定性实际设置；用户要求与实际使用不同的地方明确列出。资源窗口只作历史上下文，不写凭据，也不作为新任务授权。

## 首个差异和因果证据

| 症状/失败配置 | 相同输入是否已确认 | 对照与排除项 | 已归因机制或待验证假设 | 工件/指纹 |
|---|---|---|---|---|
| 填写本轮观测 | 说明边界 | 说明什么实验区分了假设 | 避免超过证据范围 | 相对路径或不可变标识 |

## 修改与算子契约

对每个重要改动说明：

- 原实现与改后实现；属于既有 kernel 复用、glue、数值适配还是新 kernel。
- 公式、cast/scale/reduction/clamp 顺序，参数/计算/输出 dtype。
- shape/stride/layout、metadata/ABI、mask、离散选择和状态生命周期。
- backward/saved state/STE 契约，独立参考和容差。
- 源码位置/指纹、开关、兼容性前提与耗时影响。
- 旧反例、边界和交付真实路径的复测证据。

## 验证范围

| 项目 | 状态 | 实际配置和有效计数 | 工件 | 不能推出什么 |
|---|---|---|---|---|
| 同侧重复 / BI / PD | 按实填写 | 覆盖分支与形状 | 原始位/调度记录 | 未覆盖模式 |
| native old / native grad 前向 | 按实填写 | 同版本历史与 mask | 独立执行回执 | 不等于梯度正确 |
| backward / optimizer | 按实填写 | 梯度参考、更新次数 | VJP/参数变化 | 不等于训练质量 |
| 导出 / 在线同步 / 重载 | 按实填写 | 全 worker 与派生状态 | 版本/内容/更新后输出 | 未覆盖生命周期 |
| 性能 / 质量 / 长期稳定性 | 按实填写 | 负载、数据、计时边界 | 实测值 | 不自动继承旧结果 |

## 失败尝试和证据可获得性

区分最终链与作废候选，说明最后一次重载/恢复是否真的检查。列出源码、配置、原始回执、参数连续性、退出状态及资源释放的归档位置与 SHA；只保存摘要时明确注明。未保存更新 checkpoint 时不能声称可以从哈希恢复模型。

## 可迁移经验

写出“当什么症状、什么前提成立时，尝试什么，并用什么反例/指标确认”。固定 chunk 大小、metadata 长度、TP/EP 过滤和开关属于该案例，不升为通用默认值。

列出需要重新验证的版本、几何、精度或任务变化，并链接其他相似/冲突案例。最后更新 `index.md` 的标签和证据范围。
